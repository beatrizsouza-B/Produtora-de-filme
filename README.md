# 🎬 Produtora de Filmes

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site institucional para uma produtora de filmes, com uma identidade visual moderna, elegante e profissional.

A proposta é apresentar os serviços da produtora, destacar produções audiovisuais, divulgar trabalhos realizados e facilitar o contato com clientes interessados em serviços de produção cinematográfica.

## 🎯 Objetivo

Criar uma experiência digital que transmita criatividade, profissionalismo e qualidade audiovisual, fortalecendo a presença digital da produtora e atraindo novos clientes.

## ✨ Funcionalidades

- Página inicial com apresentação da produtora.
- Seção sobre a empresa.
- Apresentação dos serviços audiovisuais.
- Galeria de filmes e produções.
- Portfólio de trabalhos realizados.
- Seção de contato.
- Layout responsivo para computadores, tablets e celulares.
- Navegação intuitiva e moderna.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilização e responsividade.
- JavaScript — interatividade e funcionalidades.

## 💻 Conceito visual

O projeto busca transmitir uma identidade cinematográfica, com design sofisticado, elementos visuais impactantes e organização profissional das informações.

## 📱 Responsividade

O site foi pensado para proporcionar uma boa experiência em diferentes dispositivos, adaptando seus elementos para telas de diversos tamanhos.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server.
